HTML Email Template

Responsive email layout built with inline CSS

A responsive email template for inboxes

This template demonstrates how HTML emails are structured using table-based layout, inline CSS, and simple responsive styling.

The layout is intentionally simple because email clients do not support modern web styling as consistently as browsers do.

This template email uses a centred container, header, main message area, content card, button, and footer.

Legacy table attributes such as width, cellpadding, cellspacing, border, and align are included alongside inline CSS to support older or inconsistent email clients.
